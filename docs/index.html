Defense in depth, measured

Not every fix is equally strong.

In the retest the injection attack is blocked because the poisoned newsletter is quarantined and never retrieved. To see what the other layers do on their own, a separate run bypassed the quarantine and counted how often the injected sentence reached the answer.

Source: findings/llm01-layers.json, 4 questions, quarantine bypassed. The LLM02 and LLM09 fixes are structural. The LLM01 and LLM08 fixes are mitigations that rely on text-matching output checks, and a reworded or translated attack could get past them.

How it works

Build it vulnerable, break it, fix it, prove it.

01 / BUILD

Vulnerable RAG

Seven fake documents for a fictional company, one shared index, no access control. Internal files carry generated RAL-CANARY secrets.

02 / ATTACK

Four questions

rag-lab attack runs one case per weakness. Deterministic detectors decide each verdict from the model's answer. No LLM judge.

03 / FIX

One fix each

SECURE_MODE=true turns on the label-based retrieval filter, prompt fencing, a separate system role and output checks.

04 / RETEST

Same harness

The identical attacks rerun with the fixes on, plus eight benign questions in both modes to measure the cost.
